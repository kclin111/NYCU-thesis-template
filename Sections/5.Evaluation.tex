% TODO ★ 這一小節要主動寫，因為審稿人一定會問為什麼不用標準的 held-out 切法 ★
%      few-shot / held-out 借的是 in-context learning 的範式：模型看過 K 個 examples
%      然後泛化到 unseen tasks。本方法不是這個形狀。
%      模板是輸入不是泛化對象——系統看得到模板不叫洩漏，叫前提，
%      而 baseline 每次執行也看得到同一份模板，兩邊對稱。
%      若 held-out 與 demonstration 共用模板則名不副實；
%      若來自不同模板則本方法必須重跑 derive，那些 examples 對它毫無作用。
%      真正需要防的是「拿資料調 prompt 而 baseline 沒被調過」，
%      對應的工具是模板層級的 dev/eval 分離。
